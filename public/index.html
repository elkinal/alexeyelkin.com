tickstore In Progress
Go · ClickHouse · WebSockets

Ingests live trade and order book feeds from several crypto exchanges and writes them somewhere you can query later. Each venue formats its feed differently, so the first layer normalizes everything into one tick schema, then maintains L2 book state per venue.

Most of the work has gone into dropped connections. Exchanges number their updates, so a gap in the sequence means the local book has quietly diverged. It detects gaps, discards the stale book, and resyncs from a snapshot. Ticks land in ClickHouse. Backfill and replay next.
